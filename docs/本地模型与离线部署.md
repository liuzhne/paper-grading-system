# 本地私有模型 + 全本地离线部署指南

把评分代码拉到本地、配本地私有模型后，整套系统可**零网络依赖**运行（不调云厂商）。本文以 **llama.cpp 为主线**，Ollama 为备选。

---

## 0. 三种 LLM 形态一览

| 形态 | `LLM_PROVIDER` | 网络 | 用途 |
|---|---|---|---|
| Mock（默认） | `mock` | **离线·不触网** | 零配置跑通流程 / 演示 / 自测 |
| 本地私有模型 | `local`（或 `llama`/`ollama`/`vllm`） | **本地·连本地端口** | 全本地离线、数据不出本机 |
| 云厂商 | `openai` / `openai_compatible` | 外呼 | 用 APIKey 调云模型 |

自检随时可看：`pgs check`（连通+延迟+network）、`pgs doctor`（是否纯本地零外呼）。

---

## 1. 本地·llama.cpp（主推）

llama.cpp 的 `llama-server` 自带 OpenAI 兼容端点，最省心。

```bash
# 1) 装 llama.cpp（见上游 README），下载一个 GGUF 量化模型，例如 Qwen3-30B-A3B-Instruct Q4_K_M
# 2) 起服务（默认 8080；--api-key 可选）
llama-server -m /path/to/model.gguf --port 8080 -c 16384 --parallel 4

# 3) 配 .env（或用 CLI 旗标，见 §3）
LLM_PROVIDER=local
LOCAL_LLM_BASE_URL=http://localhost:8080/v1
LOCAL_LLM_MODEL=local-model     # llama.cpp 忽略请求名、用已加载模型，随便填
LOCAL_LLM_API_KEY=              # 本地通常无需鉴权，留空

# 4) 自检
pgs check                       # 期望 ok=True, network=local
```

提示：
- `--parallel N` 决定并发槽位，配合 `pgs score --workers N` 提速。
- 上下文 `-c` 要够大（论文证据 + 锚点 + prompt）；显存不够就换更小量化（Q4/Q5）。
- 模型名不匹配无碍：llama.cpp 用已加载模型，忽略请求里的 model 名。

## 2. 本地·Ollama（备选）

```bash
ollama serve
ollama pull qwen2.5:14b
# .env
LLM_PROVIDER=local
LOCAL_LLM_BASE_URL=http://localhost:11434/v1
LOCAL_LLM_MODEL=qwen2.5:14b     # Ollama 需填实际模型名
```

## 3. 不写 .env：CLI 旗标一站式切换

```bash
pgs score 论文目录/ --rubric "本科毕业论文通用评分标准" \
  --provider local --base-url http://localhost:8080/v1 --model local-model
pgs check  --provider local --base-url http://localhost:8080/v1
```

## 4. 全本地离线闭环

### 4.1 离线自检
```bash
pgs doctor            # 列出网络触点（LLM / 表格导出）并判定"是否纯本地零外呼"
pgs doctor --offline  # 按离线模式预览（硬禁网络型导出）
```
纯本地的判定：**LLM=local/mock 且 表格导出=mock/Excel**（不启用 Google Sheets）。

### 4.2 硬禁外呼
设 `OFFLINE_MODE=true`（env）后，任何网络型导出（Google Sheets）会被拦截并提示改用本地 Excel：
```bash
pgs export <batch_id> -o scores.xlsx   # Excel 导出始终本地，离线可用
```

### 4.3 完整离线工作流（零网络）
```bash
LLM_PROVIDER=local OFFLINE_MODE=true \
pgs import 评分模板.xlsx --template 论文模板.docx   # 建模板
pgs score 待评论文/ --rubric <id> --report-dir 报告/  # 打分 + 报告
pgs review <run_id> --set C01=18 --note "人工下调" --submit  # 人工复核
pgs export <batch_id> -o 成绩.xlsx                   # 导出
```

## 5. 安装（拉到本地即用）

```bash
git clone <repo> && cd paper-grading-system
uv sync                       # 或 pip install -e .（依赖见 pyproject.toml / uv.lock）
pgs --help                    # console_script 入口（[project.scripts] pgs）
pgs init                      # 首次运行向导：建本地库 + 选 provider
```

CLI 默认用本地 SQLite（`~/.paper-grading/cli.db`），无需 Postgres；`pgs score --no-db --rubric-file 规则.xlsx` 可全程零落库。

> Web 形态（联网多用户）见 `docs/部署.md`。
