# 部署指南（Web 联网形态）

Web 形态为多人经网络使用提供服务：前端 + FastAPI + Postgres。本地/离线形态见 `docs/本地模型与离线部署.md`。

---

## 1. 准备

- Python 3.11+，`uv`（或 pip）。
- Postgres（生产）。开发可用 SQLite（`DATABASE_URL=sqlite+pysqlite:////tmp/dev.db`）。
- 一个 LLM provider（云 APIKey 或本地私有模型，见 §3）。

## 2. 起服务

```bash
git clone <repo> && cd paper-grading-system
cp .env.example .env && 编辑 .env       # 至少配 DATABASE_URL；LLM 默认 mock 可先跑通
uv sync
uv run alembic upgrade head             # 建表/迁移（已到 0008）
uv run uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

- 前端：访问 `/`（静态控制台）；Streamlit 仅备用。
- 健康/集成自检：`GET /api/system/integrations`（含 LLM network、offline_ready）、`/api/system/llm-check`。
- Docker：仓库带 `docker-compose.yml`（app + Postgres），`docker compose up` 起完整栈。

## 3. 配 LLM（云 / 本地，二选一）

`.env` 取消注释一套预设（见 `.env.example`）：
- 云：`LLM_PROVIDER=openai`（或 `openai_compatible`）+ API Key。
- 本地私有模型：`LLM_PROVIDER=local` + `LOCAL_LLM_BASE_URL`（即使 Web 形态也可接本地推理服务，数据不出厂商）。
- 默认 `mock`：零配置、不触网，先验证流程。

## 4. 鉴权（单租户简单登录）

默认 **关闭**（适合内网/可信网络）。公网部署务必开启：

```bash
AUTH_ENABLED=true
AUTH_USERNAME=admin
AUTH_PASSWORD=<强密码>
AUTH_SECRET=<随机长串>          # 签发会话 token，务必改默认值
AUTH_TOKEN_TTL_SECONDS=86400
```

开启后数据类端点（rubrics/batches/papers/scoring/exports/calibration）需登录；`/api/auth/login` 取 token，前端自动存 localStorage 并带 `Authorization: Bearer`。`/api/system/*` 与 `/api/auth/*` 保持开放（登录页/自检需登录前可达）。
> 单租户：一套共享凭据保护整个部署；`owner_id` 列已预留，将来多用户隔离在此基础上扩展。

## 5. 反向代理 / HTTPS

生产建议置于 Nginx/Caddy 之后，启用 HTTPS（保护登录凭据与论文数据）。限制上传体积（`MAX_UPLOAD_SIZE_MB`，默认 50）。

## 6. 运维要点

- 迁移：新增字段/端点须 `alembic upgrade head`；迁移链由 `test_migrations.py` 守护。
- 备份：Postgres + `storage/`（uploads/parsed/reports/exports）+ L0 缓存（可重建）。
- 隐私：调试日志 `LLM_DEBUG_LOG_ENABLED` 会含论文/学生 PII，生产请关闭。
- 评分定位：系统为"粗档辅助评分 + 人工复核"，不作可信排名（详见报告内说明 / `代码改造计划.md` §0）。
