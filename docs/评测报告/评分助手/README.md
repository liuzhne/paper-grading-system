每一轮真实模型评测的报告都存在这里（[Agent 化方案](../../评分助手Agent化方案.md) §27、Q8）：

- `<日期>-<期>-<模型>.md`：给人看的报告——运行信息、费用与预算、上线门槛、各类别、模型行为核对、搜索与 `call_tool`、失败条目、与上一轮对比；
- 同名 `.json`：逐条原始结果，下一轮的“已花费用”按这些文件合计。

作废的轮次（例如被限流挡住、没测到 Agent）照样留在这里：JSON 顶层标 `"obsolete": true`，Markdown 顶部有说明。它的费用照算进已花费用，但不作为下一轮“与上一轮对比”的基线。

评测在生产实例的一次性容器里跑（工作流 `pgs-assistant-eval`），用平台模型或指定的一条 AI 连接（报告里的“来源”写 platform 或 connection）；评测本身用隔离的内存数据库与合成的种子数据，**报告里没有学生信息，也不含任何密钥**。

预算（维护者 2026-10-22 授权）：每轮不超过 0.5 美元，所有轮次合计不超过 3 美元；每次正式运行前先估算并报给维护者。怎么跑见 RUNBOOK 的“评分助手评测”一节。
